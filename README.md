# NOEVIA | Beauty With Intention

## Project Overview

NOEVIA is a multi-page body care website designed to showcase a luxury-inspired beauty and self-care brand. The project focuses on creating a cohesive visual identity, organized website navigation, and an engaging product presentation.

This website was developed as part of my undergraduate coursework in Web and Digital Design and demonstrates my foundational front-end development skills.

## Live Website

[View NOEVIA Website](https://londonm2.github.io/NOEVIA-Website/)

## Technologies Used

- HTML5 — Website structure and content
- CSS3 — Styling, typography, layout, and visual presentation
- GitHub — Version control and project hosting
- GitHub Pages — Website deployment

## Website Features

- Five interconnected HTML pages
- Consistent navigation across the website
- Product photography and brand imagery
- About page highlighting the brand's story
- Product and collection information
- Contact page

## Pages

1. Home — Brand introduction and featured product
2. About — Brand story and philosophy
3. Products — Body care product information
4. Collections — Product collection presentation
5. Contact — Brand contact information
